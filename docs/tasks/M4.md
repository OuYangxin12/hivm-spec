# M4：符号档与候选性质

> 前置：M3 已完成（T3.0–T3.7 全部合入，390 passed / 2 skipped，六门禁全绿）。
> 本卡与 M1/M2/M3 卡同一纪律：**开工前定稿，改动走 PR，本地合并禁止**。

## 0. 这一程要解决什么

M3 交付了**具体执行档**：给定一组具体输入，两份 IR 跑出来的中间值逐 op 比对。
它的结论形式是"**在这组输入上**没发现发散"。

M4 要把结论提升为"**在有界范围内的所有输入上**没发现发散"。这是从"测试"到
"验证"的跨越，也是 FR1 真正意义上的兑现。

同时，M3 实测暴露了具体档的两条硬边界（见 M3 卡 §8.4），符号档恰好能部分绕开：

| M3 的阻断 | 影响面 | M4 的出路 |
|---|---|---|
| 逃生舱 op `mmadL1` 无具体值语义 | 20/41 语料整链失去可比性 | 符号档比**结构等价**，不需要具体值——`mmad(a,b)` 作为未解释函数（uninterpreted function）两侧一致即可 |
| 动态 shape 入参不猜具体值 | 20/41 语料 | 符号 shape，或用户显式提示 |

**但必须先说清楚 M4 不承诺什么**：符号档不会让 41 份语料全变 OK。受限子集
（D4/OD6）是**设计约束**而非临时偷懒，子集外的 op 仍然如实报缺口。

## 4. 设计要点（开工前约定，防走样）

1. **符号档不替代具体档，二者结论并列**。UNSAT（有界内无反例）与"具体输入上
   一致"是不同强度的结论，报告必须分别标注，不得混为一谈。

2. **未解释函数是逃生舱 op 的正解，不是万金油**。`mmadL1` 两侧都建模成同一个
   未解释函数 `f(a,b)`，则"两侧都调用 `f` 且实参相同"可判等价——但这**只能证明
   两侧做了相同的事，不能证明那件事是对的**。报告措辞必须区分这两者。

3. **受限子集之外必须报缺口，不得偷偷放行**。`SYMBOLIC_OPS` 是封闭集合，超出
   即报错（T3.1 已如此）。M4 不放松这条。

4. **z3 求解超时按缺口处理，不按通过处理**。超时的含义是"没证出来"，不是
   "证明了没问题"（FR6）。必须有显式超时上限并在结论中回显。

5. **poison 填充不得与合法值冲突**。未初始化读检查依赖"读到 poison = 读了未初始
   化内存"，故 poison 值不能是可能合法出现的数值（NaN 也不安全——真实计算会产生
   NaN）。需要独立的 tainted 标记位而非魔数。

6. **T4.4 是账本级快速检查，不做时序模拟**。它与 M2 的 timeline 工具**互补**：
   timeline 做交错探索（重），T4.4 做静态配对计数（轻）。二者结论不一致时以
   timeline 为准，且必须暴露不一致本身。

7. **有界范围必须显式声明并进结论**。"有界内无反例"里的"界"是结论的一部分，
   缺了它读者会误读为无条件成立——与 M2 截断语义同理。

## 5. 风险与止损

| 风险 | 触发 | 止损 |
|---|---|---|
| z3 引入使 CI 显著变慢或不稳 | T4.0 评估 | 列为可选依赖；核心测试不依赖 z3；缺失时报 PENDING |
| 符号执行状态爆炸 | T4.2 | 收紧界（循环展开数/路径数）并在结论中声明；不得静默截断 |
| 受限子集覆盖太窄导致 T4.2 无实用价值 | T4.2 验收 | 如实记录覆盖面（如 T3.7 的做法）；范围可缩，能力不删 |
| 未解释函数被误读为"验证了 MMA 正确性" | T4.2 报告 | 措辞硬性区分（见 §4.2）；加测试锁定报告文案 |
