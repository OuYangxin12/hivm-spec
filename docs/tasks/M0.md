## 4. 风险与止损

| 风险 | 触发信号 | 处置 |
|---|---|---|
| VIR 表达力不足 | L0/L1 语料出现无法表达的结构 | 按框架 §6.1 版本化演进契约；**不允许**私有分支解释核（D6） |
| 语法 spike 暴露表达力悬崖 | 三 op 有 ≥2 落逃生舱 | 停下重估 §4.4 概念清单边界，再定 T0.1 API |
| L1 语料 `COVERAGE_GAP` 过多 | 选入的干净 UT 大量报缺口 | 降级留在 L2 待建模补齐，不放宽 L1 门槛（D13） |
| IR 接口层无法本地验证 | cp310 绑定不可得 | `requires_bindings` 跳过并登记缺口；**T0.0/T0.0d 的 L0 部分不依赖绑定**（纯 Python 构造 VIR） |

> **需上报决策的情形**：① 三 op spike 有 ≥2 落逃生舱（DSL 范围需重估）；
> ② VIR 契约需引入 §6.1 未列的新概念；③ L1 语料揭示 §4.2 概念清单缺项。
